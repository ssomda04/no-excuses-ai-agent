# No Excuses AI Agent

[ 프로젝트 선정 배경 및 목적 ]
🚩 기획 의도: "의지"를 탓하기 전에 "데이터"로 반박하라
문제 정의의 타당성: 대부분의 운동 실패는 계획의 부재가 아니라 '자기합리화'에서 비롯됩니다. 고가의 PT가 효과적인 이유는 코치가 개인의 상태를 점검하고 핑계를 허용하지 않는 '강제력'을 제공하기 때문입니다. 본 프로젝트는 이 강제력을 AI와 객관적 데이터로 대체하여, 운동 결심을 실행으로 옮기게 하는 장치를 구축하고자 했습니다.

아이디어의 창의성 및 차별성: 단순히 "운동하세요"라고 독촉하는 기존 방식에서 벗어나, 사용자의 핑계를 날씨, 일정, 수면 데이터라는 객관적 증거로 검증하여 논리적으로 반박하는 '비판적 사고 에이전트' 컨셉을 도입했습니다. 이는 김동현 선수의 '팩트 기반 동기부여' 밈에서 아이디어를 얻어,이를 IT 기술로 구현한 독창적인 시도입니다.

기획의 설득력: 운동 결심을 '심리적 의지'의 영역에서 '논리적 실행'의 영역으로 전환하여, 사용자가 스스로 만든 핑계의 모순을 깨닫고 행동하게 만드는 강력한 설득력을 갖췄습니다.

[ 주요 기능 및 구현 과정 ]
⚙️ 핵심 기능 구현의 완성도
본 시스템은 사용자의 주관적인 변명을 객관적인 데이터로 필터링하는 Multi-Step Reasoning 구조로 설계되었습니다.

초개인화 온보딩 시스템:

사용자로부터 이름, 신체 정보(키, 체중), 운동 목적, 요일별 상세 시간을 입력받습니다.

입력된 데이터를 바탕으로 AI가 운동 강도를 판단하고, 개별 스케줄에 맞춘 최적화된 조언을 제공합니다.

데이터 기반 핑계 검증 엔진 (Fact-Check Logic):

날씨 (OpenWeather API): 외부 운동이 불가능한 기상 조건인지 실시간으로 검증합니다.

일정 (Google Calendar API): 운동 시간대에 실제 겹치는 일정이 있는지 조회하여 시간 핑계의 진위를 판별합니다.

컨디션 (Google Fit API): 수면 데이터를 분석하여 사용자의 피로도가 객관적으로 운동이 불가능한 수준인지 확인합니다.

🎨 사용자 중심의 UX/UI 설계
본 시스템은 사용자가 '거절할 수 없는 환경'을 조성하는 데에 집중했습니다.

Streamlit 대화형 인터페이스: 복잡한 설정 없이 대화하듯 핑계를 입력하면 즉시 분석 결과(유형, 신뢰도, 정책)를 시각적으로 보여줍니다.

대안 제시 시스템: 핑계가 정당하다고 판단될 경우(예: 실제 폭우), 운동을 포기하게 두는 것이 아니라 즉시 실행 가능한 실내 운동 유튜브 루틴을 화면에 렌더링하여 실행력을 끝까지 유지합니다.

시각적 마감도 및 분석:

캘린더 UI: 사용자의 운동 여부와 핑계 이력을 기록하여 스스로 계획 성공률을 한눈에 확인할 수 있게 시각화했습니다.

행동 패턴 분석: 단기간에 동일한 핑계를 반복하면 AI가 이를 감지하여 더 강력한 동기부여 메시지를 전달하거나 계획 조절을 제안합니다.

💡실제 실행 화면
사용자 정보 입력 란 : 이름, 키, 체중, 운동목적 (체중 감량, 체력 향상, 스트레스 해소, 습관 형성), 운동 요일, 각 선택 요일 별 운동 시간 설정

이때 입력한 키, 체중, 운동 목적과 운동 시간을 통해 운동 강도에 대해 AI가 판단하여 운동계획에 대한 조언을 제공합니다.

요일 별 운동 시간을 다르게 설정할 수 있어 개별 스케쥴에 맞추어 운동 계획을 설정할 수 있습니다.

ex) 실제 실행 화면

운동정보 기록: 계획한 운동 요일에 운동 여부를 기록. 못했을 경우 사용자의 핑계를 자연어로 입력받아 agent가 이를 데이터를 통해 검증.

사용자가 날씨 핑계를 댈 경우 - weather API에서 가져온 정보를 토대로 정말 운동하기에 어려운 날씨인지 검증함. 실제로 외부에서 운동하기가 어려운 경우에는, 실내 운동을 제안하여 유튜브 링크를 제공합니다.

사용자가 스케쥴 핑계를 댈 경우 - google calendar API에서 가져온 정보를 토대로 정말 운동하기 어려운 스케쥴인지 검증함. 실제로 다른 일정이 존재하여 운동하기가 어려운 경우에는, 일정과 겹치지 않는 시간대로 대체하여 운동을 추천합니다.

사용자가 컨디션 핑계를 댈 경우 - 수면 데이터를 바탕으로 사용자가 정말 컨디션 이슈로 운동하기 어려운 상태인지 검증합니다. 무작정 운동으로 밀어붙이는 것이 아니라, 체력과 컨디션을 모두 고려하여 휴식을 추천하거나 가벼운 운동을 제안합니다.

하지만 사용자가 단기간에 같은 핑계를 지속적으로 제시한다면, 더욱 강한 동기부여 멘트를 내보이거나, 운동계획 조절을 제안합니다.

ex. 날씨 핑계를 댈 경우

ex. 스케쥴 핑계를 댈 경우

ex. 컨디션 핑계를 댈 경우

기록 및 패턴: 캘린더 형식의 UI/UX를 통해 사용자의 운동여부와 핑계들을 기록하여 데이터 분석 결과를 시각화 함.

사용자 입력 당시 설정한 운동 계획 요일에 운동하는 것을 기본으로 하되, 그 외의 요일에도 운동을 했다면 추가적인 기록을 하여 운동의지를 향상시킵니다.

한눈에 보이는 기록을 통해 스스로의 계획 성공률을 확인할 수 있습니다.

[ 기술적 문제 발생 시 해결 사례 (Troubleshooting) ]
문제 (Problem): google fit API를 통해 수면 데이터를 불러와 사용자의 건강 정보를 토대로 사용자의 건강, 컨디션 관련 핑계를 검증하고 논리적으로 반박하는 로직을 구현하려 했으나, 안드로이드를 사용하지 않아 데모기간 내에 충분한 데이터를 수집할 수 없었습니다.

해결 (Solution): create_simple_data.py 모듈을 개발하여 임의로 수면 mock 데이터를 생성하여 로직을 검증하고 이를 토대로 데모 버전을 설계하였습니다. 추후 google fit API만 연결하면 바로 데이터를 가지고 올 수 있도록 구조를 만들어두었습니다. 다만, 현재 google calendar API는 제걸로 연동되어 있어, 나중에 이를 수정하여 사용자 별 API를 참조할 수 있도록 해야 할 것 같습니다.

문제 (Problem): 사용자가 핑계를 댈 때마다 DB에 로그가 쌓이지만, 단순히 쌓이기만 해서는 사용자에게 경고를 주기 어려웠습니다.

해결 (Solution): insights.py 모듈을 개발하여 특정 기간 내 동일 유형의 핑계가 반복될 경우 AI가 이를 감지하고 "최근 7일간 시간 핑계를 3번이나 하셨네요"라는 식의 누적 패턴 경고 기능을 구현했습니다.

[ 프로젝트의 가치 및 기대 효과]
현실성 및 유용성: 본 프로젝트는 단순한 운동 기록 앱을 넘어, 사용자의 심리적 허점을 데이터로 보완하는 실용적인 해결책을 제시합니다.

자기 합리화의 해결: 사용자가 스스로 만든 핑계와 실제 데이터(날씨, 일정 등) 사이의 모순을 즉각적으로 대면하게 함으로써, 자기합리화를 차단하고 실행력을 높입니다.

심리적 저항을 낮추는 적응형 대안: 외부 운동이 불가능한 객관적 상황(폭우, 폭설 등)에서는 무조건적인 강요 대신 즉시 홈트레이닝 루틴을 제공하여, 운동의 흐름이 끊기지 않도록 돕는 현실적인 유연성을 갖추고 있습니다.

기대 효과 및 향후 확장성:

게이미피케이션 요소 및 커뮤니티 연동: 여러 사용자의 '핑계 격파 성공률(핑계 입력 후 최종 운동 완료 횟수)'을 랭킹화하여 사용자 간의 긍정적인 경쟁을 유도할 수 있습니다. 또한, 커뮤니티나 챌린지 서비스를 도입하여 사용자들의 적극적인 참여를 도모할 수 있습니다.

아키텍처의 확장성: 현재 연동된 API 외에 향후 식단 관리, 건강검진 결과, 웨어러블 기기의 실시간 생체 데이터등을 쉽게 추가 할 수 있는 구조로 설계되었습니다.

선제적 기능 탑재: 사용자가 앱을 켜기 전, AI agent가 먼저 "지금 운동하기 가장 좋은 조건"임을 인지하고 알림을 주는 선제적 기능을 탑재하여 사용자의 편의성을 극대화 할 예정입니다.

비즈니스 모델: 개인 트레이너(PT)들이 회원의 비대면 관리를 돕는 보조 툴로 활용할 수 있는 높은 상업적 잠재력을 지니고 있습니다.

[ 프로젝트 완주 소감 ]
처음 LangGraph와 AI Agent를 설계하며 프로젝트를 시작했을 때는, 단순한 챗봇을 넘어 '스스로 사고하고 도구를 호출하는 에이전트'를 구현한다는 것이 큰 도전이었습니다. 교육 시간에 배운 개념을 실제 서비스에 이식하는 과정에서 수많은 시행착오를 겪었지만, 코드가 의도대로 작동하여 사용자의 핑계를 팩트로 반박하는 순간 '데이터 기반의 의사결정'이 가진 강력한 힘을 체감할 수 있었습니다. 구현 목표를 하나씩 달성할수록 "더 정교하게 반박할 수는 없을까?", "사용자의 미세한 패턴까지 분석하면 어떨까?" 하는 기술적 욕심이 커져갔습니다. 처음에는 MVP 완성에 집중했지만, 점차 디테일한 심화 기능을 추가하게 된 것은 바로 이 '욕심'이 성장의 동력이 되었기 때문입니다. 이 과정은 단순한 기능 구현을 넘어, 사용자 경험(UX)을 깊이 고민하는 개발자로 성장하는 소중한 계기가 되었습니다. 이번 프로젝트를 통해 AI 에이전트가 우리 실생활의 문제들을 어떻게 기술적으로 해결할 수 있는지 가능성을 보았습니다. 비록 첫 시도라 부족한 점도 있었지만, 향후 더 다양한 외부 데이터 API를 연동하고 추론 경로를 최적화하여, 누구에게나 핑계 없는 삶을 선물하는 '완벽한 AI 코치'로 발전시켜 나가고 싶습니다.
