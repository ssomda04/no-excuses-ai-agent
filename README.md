# No Excuses AI Agent

"의지를 탓하기 전에, 데이터로 반박하라" - 데이터 기반 비판적 사고 AI 코치
📝 프로젝트 개요
대부분의 운동 실패는 계획의 부재가 아니라 '자기합리화'에서 비롯됩니다. 본 프로젝트는 사용자의 운동 핑계를 날씨, 일정, 수면 데이터라는 객관적 증거로 검증하고, 논리적으로 반박하여 실행력을 강제하는 '비판적 사고 에이전트'입니다.

핵심 컨셉: 김동현 선수의 '팩트 기반 동기부여' 밈에서 착안하여, AI와 객관적 데이터를 통해 사용자의 핑계 모순을 깨닫고 행동하게 만드는 서비스.

⚙️ 주요 기능
1. 초개인화 온보딩
이름, 신체 정보(키, 체중), 목적, 요일별 상세 시간을 입력하여 맞춤형 운동 강도 조절 및 스케줄링.

2. 데이터 기반 핑계 검증 엔진 (Fact-Check Logic)
사용자가 운동을 거부할 때, AI가 실시간 데이터를 바탕으로 핑계의 진위를 분석합니다.

날씨 (OpenWeather API): 실외 운동 적합 여부 판단.

일정 (Google Calendar API): 운동 시간대 실제 스케줄 충돌 여부 확인.

컨디션 (Google Fit API): 수면 데이터를 분석하여 피로도 및 운동 가능 여부 판단.

3. 적응형 대안 제시
정당한 핑계(예: 폭우) 시: 즉시 실행 가능한 실내 홈트레이닝 유튜브 루틴 제공.

일정 충돌 시: 겹치지 않는 시간대 재제안.

단순 핑계 시: 강력한 동기부여 및 팩트 폭격.

4. 시각화 및 행동 패턴 분석
캘린더 UI: 운동 이력 및 핑계 이력 시각화.

행동 패턴 분석 (Insights): 반복되는 핑계 감지 시, 더 강력한 경고 메시지 전달 및 계획 수정 제안.

🛠 기술 스택 및 구현 방법
Framework: LangGraph, AI Agent (Multi-Step Reasoning)

UI/UX: Streamlit

External APIs: OpenWeather, Google Calendar, Google Fit

Troubleshooting:

Data Mocking: create_simple_data.py를 통한 수면 데이터 모의 생성 및 검증.

Logic Optimization: insights.py를 통한 누적 패턴 분석 및 경고 시스템 구현.

📊 프로젝트 아키텍처 및 흐름
🚀 기대 효과 및 향후 계획
자기 합리화 차단: 심리적 저항을 데이터로 돌파하여 실행력 극대화.

게이미피케이션: '핑계 격파 성공률' 랭킹 도입 및 커뮤니티 기능 확장.

아키텍처 확장: 식단, 생체 데이터(웨어러블), 건강검진 결과 등으로 확장성 확보.

비즈니스 모델: PT(개인 트레이너)의 비대면 회원 관리 보조 툴로 활용 가능.

💡 완주 소감
LangGraph를 활용하여 단순 챗봇을 넘어 스스로 사고하고 도구를 호출하는 에이전트를 설계하는 과정은 큰 도전이었습니다. 데이터를 통해 사용자의 핑계를 논리적으로 반박하는 기능을 구현하며 '데이터 기반 의사결정'의 힘을 체감했습니다. 앞으로 더 정교한 추론 경로와 다양한 API 연동을 통해 누구에게나 핑계 없는 삶을 선물하는 '완벽한 AI 코치'로 발전시키고 싶습니다.
